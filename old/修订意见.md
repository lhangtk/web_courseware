《前端技术核心概念与原理解析》修订建议
课程简介
本课程旨在带领学员深入理解前端技术的核心概念与底层原理。课程将从浏览器基础开始，逐步深入 HTML、CSS 和 JavaScript 的语言核心，解析浏览器如何渲染页面、JavaScript 引擎如何执行代码，并探讨现代前端开发的思维模式和工程化基础。通过本课程的学习，学员将建立起系统化的前端知识体系，能够更自信地应对复杂问题和学习新技术。课程时长建议4 学时，分为上下两讲。
课程目标

- 理解本质：掌握 Web 标准（HTML、CSS、JavaScript）的设计初衷与核心思想。
- 深入原理：剖析浏览器渲染机制、JavaScript 执行机制（事件循环、作用域链、原型链等）。
- 建立体系：构建从语言特性到浏览器实现的前端知识图谱。
- 提升能力：培养通过原理解决实际开发中复杂问题（如性能优化、兼容性问题）的能力。
课程大纲（参考）
第1章：Web 前端概述

- Web 的体系结构：客户端-服务器模型、URL 到页面的旅程、HTTP/HTTPS 协议基础 。
- Web 标准三剑客：结构（HTML）、表现（CSS）、行为（JavaScript）的分离与协作 。
- 核心概念解析：浏览器与内核，主流浏览器（Chrome、Firefox、Safari、Edge）及其内核（Blink、Gecko、WebKit）的区别。渲染引擎与 JS 引擎，介绍浏览器两大核心引擎的分工。

第2章：浏览器渲染原理

- 导航与解析：从输入 URL 到开始解析 HTML 的过程（DNS 解析、TCP 连接、TLS 协商、HTTP 请求与响应）。
- 关键渲染路径：HTML 解析与 DOM 树构建；CSS 解析与 CSSOM 树构建；JavaScript 的阻塞与优化；渲染树（Render Tree）构建；布局（Layout/Reflow）与绘制（Paint）。渲染层与合成，理解图层（Layer）的概念，以及硬件加速的原理。

第3章：HTML 核心与语义化

- HTML 设计原理：SGML 与 XML 的影响，HTML5 的设计理念（兼容、实用、互通）。
- HTML语义化：为什么需要语义化？语义化标签的选用原则等。
- 元素的分类与嵌套规则：块级元素、行内元素、行内块元素的本质区别与法律 。
- 现代 HTML 特性与 API 简介：表单的演变与表单验证机制（约束验证 API）的原理；多媒体与图形；丰富的Web API 等。

第4章：CSS 核心机制

- CSS 层叠与继承：样式冲突解决的优先级规则（重要性、专用性、源代码顺序）；哪些属性可被继承及其原理。
- 盒模型（Box Model）深度解析：标准盒模型与怪异盒模型的对比；`box-sizing` 的实际应用原理。
- 视觉格式化模型：定位的包含块原理；格式化上下文，BFC、IFC的创建规则与作用。
- 现代布局系统：弹性布局；网格布局；响应式设计原理，视口的概念与设置，媒体查询（Media Queries）的逻辑与断点设置，相对单位（`rem`、`em`、`vw`、`vh`）的适用场景与计算原理。
- CSS 性能与优化：CSS 选择器的匹配规则；避免重排（Reflow）与重绘（Repaint）的 CSS 属性选择。
- CSS的过渡与动画。

第5章：JavaScript 核心原理解析

- 执行上下文与作用域链：全局上下文、函数上下文、Eval 上下文；变量对象/ 活动对象的创建过程。作用域与作用域链。
- 闭包的本质：闭包的形成条件、原理（保留作用域链）、内存占用及实际应用。
- 原型链：`__proto__` 与 `prototype` 的区别；如何通过原型链实现继承；基于原型的继承与基于类的继承的对比。
- this 关键字：`this` 的四种绑定规则（默认绑定、隐式绑定、显式绑定、new 绑定）；箭头函数中 `this` 的特殊性（由词法作用域决定）。
- 类（Class）语法：ES6 `class` 的本质（语法糖），`extends` 继承的内部实现（如何通过原型链实现继承）。
- 事件循环（Event Loop）： JavaScript 的单线程与异步的关系；调用栈（Call Stack）、任务队列（Task Queue）、微任务队列（Microtask Queue）；宏任务（MacroTask）与微任务（MicroTask）的执行顺序（`setTimeout`、`Promise`、`async/await` 的执行分析）。
- Promise：解其核心逻辑。
- async/await 语法：Generator 函数与 Promise 的语法糖，其执行流程解析。
- 跨域解决方案：同源策略（Same-Origin Policy），为什么要有同源策略？CORS（跨域资源共享）**，简单请求与复杂请求（预检请求 `OPTIONS`）的原理。
- Fetch API：基于 Promise 的现代化请求方式，与 XHR 的对比。
- WebSocket 和 SSE。

第6章：课程总结

- 复盘前端核心知识图谱。
